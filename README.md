# SeaWorld Water Chemistry Console v14

Pump module redesigned around six tasks:
- Overview
- Selection
- Operating Point
- Field Tools
- Curves
- Reference

Energy comparison:
- Estimated shaft HP = motor nameplate HP × (required Hz / 60)^3
- Estimated input kW applies user-entered motor and VFD efficiency
- Annual kWh and cost use user-entered runtime and electric rate
- Values are screening estimates, not Pentair-certified BHP or efficiency data

The incident PDF workflow and all chemistry calculators remain included.
