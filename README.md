# SeaWorld Water Chemistry Console v13

New Pentair EQ Pump Sizing tab:
- Desired GPM and TDH inputs
- Minimum and maximum VFD frequency
- Required operating-frequency reserve
- Comparison of all six EQ/EQW models
- Required Hz
- Percent rated speed
- Remaining frequency reserve
- Water horsepower
- Ideal speed-cubed power percentage
- Idealized savings versus the selected baseline
- Capability and preferred-selection ranking

Deliberately omitted because manufacturer data is unavailable:
- Brake horsepower
- Pump efficiency
- Motor efficiency
- Input kW
- Annual energy cost
- NPSHr

The ideal power and savings columns are affinity-law screening values only and are not electrical-consumption guarantees.
